## 🛠️ Technical Requirements

### Tech Stack Details:
- **Framework:** Next.js 16+ (App Router) - For SSR/SSG & SEO
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** Shadcn UI
- **Routing:** Next.js App Router (file-based routing)
- **SEO:** Built-in Next.js SEO features
  - Server-Side Rendering (SSR)
  - Static Site Generation (SSG)
  - Automatic meta tags
  - Sitemap generation
  - robots.txt support

### Why Next.js for Marketing Website?
✅ **Better SEO:**
  - Server-Side Rendering (SSR) - Content rendered on server
  - Static Site Generation (SSG) - Pre-rendered pages
  - Better search engine indexing
  - Faster initial page load

✅ **Performance:**
  - Automatic code splitting
  - Image optimization
  - Font optimization
  - Built-in caching

✅ **Developer Experience:**
  - File-based routing
  - API routes (if needed)
  - Easy deployment (Vercel, etc.)
  - TypeScript support

### Requirements:
- Responsive design (Mobile-first)
- Fast loading (< 3 seconds)
- SEO optimized (meta tags, schema markup)
- Accessible (WCAG compliant)
- Cross-browser compatible
- Analytics integration (Google Analytics)
- Sitemap.xml generation
- robots.txt configuration

## 📦 Next.js Features to Use

### 1. **Server Components (Default)**
- Better performance
- Automatic code splitting
- SEO-friendly

### 2. **Metadata API**
```typescript
// app/about/page.tsx
export const metadata = {
  title: 'About Us - SmartlyBuild',
  description: 'Learn about our mission...',
  openGraph: {
    title: 'About Us',
    images: ['/og-image.jpg'],
  },
}
```

### 3. **Static Generation (SSG)**
```typescript
// For pages that don't change often
export const revalidate = 3600; // Revalidate every hour
```

### 4. **Server-Side Rendering (SSR)**
```typescript
// For dynamic content
async function getData() {
  const res = await fetch('...');
  return res.json();
}
```

### 5. **Image Optimization**
```tsx
import Image from 'next/image';

<Image
  src="/hero.jpg"
  alt="Hero"
  width={1200}
  height={600}
  priority
/>
```

### 6. **Dynamic Routes**
```typescript

}
```

### 2. **Sitemap Generation**
```typescript
// app/sitemap.ts
export default function sitemap() {
  return [
    {
      url: 'https://example.com',
      lastModified: new Date(),
      changeFrequency: 'yearly',
      priority: 1,
    },
    // ... more URLs
  ]
}
```

### 3. **robots.txt**
```typescript
// app/robots.ts
export default function robots() {
  return {
    rules: {
      userAgent: '*',
      allow: '/',
      disallow: '/admin/',
    },
    sitemap: 'https://example.com/sitemap.xml',
  }
}
```

### 4. **Schema Markup**
```typescript
// Use next-seo or manual JSON-LD
export default function HomePage() {

    // ...
  };
  
  return (
    <>
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{ __html: JSON.stringify(jsonLd) }}

  );
```

## 🚀 Why Next.js is Better for Marketing Site

### SEO Benefits:
- ✅ **Server-Side Rendering** - Content available on first load
- ✅ **Static Generation** - Pre-rendered HTML for better indexing
- ✅ **Automatic Optimization** - Image, font, script optimization
- ✅ **Better Core Web Vitals** - Faster loading, better ranking

### Performance:
- ✅ **Code Splitting** - Only load what's needed
- ✅ **Image Optimization** - Automatic WebP, lazy loading
- ✅ **Font Optimization** - Self-hosted fonts, no layout shift

### Developer Experience:
- ✅ **File-based Routing** - No route config needed
- ✅ **TypeScript Support** - Built-in
- ✅ **Easy Deployment** - Vercel, Netlify, etc.
