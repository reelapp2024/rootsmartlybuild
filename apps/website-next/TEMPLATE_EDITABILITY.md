# HeroWithBackground Template - Complete Editability Guide

## ✅ **हाँ, Template पूरी तरह Editable है!**

जब आप Studio Builder में `HeroWithBackground` template add करते हैं, तो यह **Section/Row/Column/Element** structure में convert हो जाता है, जिससे **हर part editable** हो जाता है।

## 🎨 क्या-क्या Edit कर सकते हैं:

### 1. **Section Level (पूरा Hero Section)**
✅ **Background:**
- Background color
- Background image (upload या URL)
- Background size, position, repeat
- Gradient colors

✅ **Layout:**
- Container width (full width, boxed, custom)
- Min height, Max height
- Padding (top, right, bottom, left)
- Margin
- Display type (flex, grid, block)
- Flex direction, justify content, align items
- Gap between items

✅ **Spacing & Borders:**
- Border width, style, color, radius
- Box shadow
- Overflow settings

✅ **Position:**
- Position (static, relative, absolute, fixed)
- Top, right, bottom, left
- Z-index

✅ **Responsive:**
- Desktop, Tablet, Mobile breakpoints के लिए अलग-अलग styles

### 2. **Row Level (Content Container)**
✅ **Layout:**
- Background color/image
- Padding, Margin
- Display, Flex direction
- Justify content, Align items
- Gap

✅ **Responsive:**
- Breakpoint-specific styles

### 3. **Column Level (Overlay Box)**
✅ **Overlay Styling:**
- Background color (overlay effect)
- Background image
- Padding, Margin
- Max width, Width
- Border radius
- Border, Box shadow

✅ **Layout:**
- Display, Flex direction
- Justify content, Align items
- Gap

✅ **Responsive:**
- Breakpoint-specific styles

### 4. **Heading Element**
✅ **Content:**
- Heading text (editable directly on canvas)
- Heading tag (h1, h2, h3, h4, h5, h6)
- Icon (add, remove, position)
- Link (add URL, target, rel)

✅ **Typography:**
- Font family, Font size, Font weight
- Text color, Background color
- Line height, Letter spacing
- Text align, Text transform
- Text decoration

✅ **Spacing:**
- Padding, Margin
- Border, Border radius
- Box shadow

✅ **API Configuration:**
- Enable/Disable dynamic content
- API URL
- HTTP Method (GET/POST)
- Data path (JSON path)
- Refresh interval
- Fallback to static content

✅ **Responsive:**
- Breakpoint-specific styles

### 5. **Description Element**
✅ **Content:**
- Description text (editable directly on canvas)
- HTML content support
- Rich text editing

✅ **Typography:**
- Font family, Font size, Font weight
- Text color, Background color
- Line height, Letter spacing
- Text align

✅ **Spacing:**
- Padding, Margin
- Border, Border radius

✅ **Background:**

✅ **API Configuration:**

✅ **Responsive:**
- Breakpoint-specific styles

## 🛠️ Editing Features:

### **Context Menu (Right Click):**
- ✅ **Move Up/Down** (Section, Row, Column, Element)
- ✅ **Duplicate** (Section, Row, Column, Element)
- ✅ **Delete** (Section, Row, Column, Element)
- ✅ **Settings** (open settings panel)

### **Drag & Drop:**
- ✅ Reorder sections
- ✅ Reorder rows within sections
- ✅ Reorder columns within rows
- ✅ Reorder elements within columns

### **Add More:**
- ✅ Add new rows to section
- ✅ Add new columns to row
- ✅ Add new elements (heading, text, description, button, image, etc.)

### **Section Navigator:**
- ✅ See all sections in sidebar
- ✅ Quick navigation
- ✅ Section management

## 📋 Step-by-Step Editing:

### **Section Edit करने के लिए:**
1. Section पर click करें
2. Right sidebar में "Section Settings" open होगा
3. Tabs: Content, Style, Advanced
4. हर property edit कर सकते हैं

### **Row Edit करने के लिए:**
1. Row पर right-click करें
2. "Settings" select करें
3. Row settings panel open होगा
4. Layout, spacing, background edit करें

### **Column Edit करने के लिए:**
1. Column पर right-click करें
2. "Settings" select करें
3. Column settings panel open होगा
4. Overlay, padding, width edit करें

### **Element Edit करने के लिए:**
1. Element पर click करें
2. Right sidebar में element settings open होगा
3. Content tab: Text, icon, link edit करें
4. Style tab: Colors, fonts, spacing edit करें
5. Advanced tab: API configuration edit करें

## 🎯 Example Edits:

### **Background Image Change:**
1. Section select करें
2. Style tab → Background Image
3. Upload image या URL paste करें
4. Size, position adjust करें

### **Overlay Color Change:**
1. Column select करें (overlay box)
2. Column settings → Background Color
3. Color picker से color select करें
4. Opacity adjust करें

### **Heading Text Change:**
1. Heading element पर double-click करें
2. Text directly edit करें
3. या settings panel में "Content" tab से edit करें

### **Add Button:**
1. Column में right-click करें
2. "Add Element" → "Button" select करें
3. Button settings से text, link, style edit करें

### **Disable API:**
1. Heading या Description element select करें
2. Advanced tab → API Configuration
3. "Enable Dynamic Content" toggle off करें
4. Static content use होगा
